# Tic Tac Toe

A browser-based version of the classic Tic Tac Toe game, built as part of a personal front-end portfolio with focus on clarity, interaction, and simple gameplay.

## Live Demo

https://laurandreea10.github.io/Tic-Tac-Toe/

## Features

* Classic Tic Tac Toe gameplay
* Interactive browser-based experience
* Clean and simple game layout
* Responsive front-end structure
* Easy-to-follow interface
* GitHub Pages deployment

## Technologies

* HTML
* CSS
* JavaScript
* GitHub Pages

## Purpose

This project was created as a personal front-end experiment exploring classic game mechanics, interface clarity, and interactive browser gameplay in a simple web format.
